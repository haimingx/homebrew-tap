# homebrew-tap

Homebrew formulas for CLI tools.

## Usage

```bash
brew tap haimingx/tap
```

## Formulas

| Formula | Description | Install |
|---|---|---|
| [aiswap](https://github.com/haimingx/aiswap) | Zero-proxy account switcher, quota monitor, and TUI for Claude Code, Codex CLI, and Antigravity | `brew install haimingx/tap/aiswap` |
| [chaintable](https://github.com/haimingx/chaintable-cli) | Command-line client for Chaintable: on-chain SQL, live tables, chain state, and BlockX compute | `brew install haimingx/tap/chaintable` |
